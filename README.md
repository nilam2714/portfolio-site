# Neelam — Portfolio

Personal portfolio site built with [Astro](https://astro.build), deployed on Cloudflare Pages.

## Commands

| Command | Action |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Start local dev server |
| `npm run build` | Build to `./dist` |

## Editing content

Services and projects are arrays at the top of `src/pages/index.astro`.

## Deploy

Cloudflare Pages → Astro preset, build command `npm run build`, output `dist`.
